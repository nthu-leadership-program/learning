# 架設與部署

> 這份文件只有**第一次架站**或**換資料來源**時需要。平常上架單元不用看。

## 1. 建立 GitHub repository

1. 用立德的 GitHub 帳號登入，建議建立 Organization（例如 `lide-nthu`），repo 放在 Organization 下，交接時不會跟著個人帳號消失
2. 點「New repository」，名稱例如 `learning`，選 **Public**（GitHub Pages 免費版需要公開 repo）
3. 點「uploading an existing file」，把這個資料夾裡的**所有檔案和資料夾**拖進去
4. 按「Commit changes」

## 2. 開啟 GitHub Pages

1. 在 repo 點「Settings」→ 左側「Pages」
2. 「Source」選「Deploy from a branch」
3. 「Branch」選 `main`，資料夾選 `/ (root)`，按「Save」
4. 等 1–2 分鐘，頁面上方會出現網址，格式是 `https://組織名稱.github.io/repo名稱/`

把這個網址交給老師，放到立德官網的按鈕或連結上。

## 3. 接上 Google 試算表

1. 依 [試算表欄位說明](05-試算表欄位說明.md) 建立試算表並「發布到網路」，取得兩個 CSV 網址
2. 在 GitHub 打開 `js/config.js`，點鉛筆 ✏️ 編輯
3. 把網址貼進引號裡：

   ```js
   unitsCsvUrl: "https://docs.google.com/spreadsheets/d/e/XXXX/pub?gid=0&single=true&output=csv",
   quizzesCsvUrl: "https://docs.google.com/spreadsheets/d/e/XXXX/pub?gid=123456&single=true&output=csv",
   ```

4. Commit，約 1 分鐘後網站更新

> 網址留空 `""` 時，網站會讀取 `data/` 資料夾裡的示範資料。

## 4. 本機預覽（選用）

改外觀或程式時，可以先在自己電腦上測試：

```bash
python -m http.server 8000
```

打開 <http://localhost:8000>。改完確認沒問題再上傳 GitHub。

## 換主題色

打開 `css/style.css`，最上面的 `:root` 區塊：

- `--t0`、`--t1`、`--t2`：三大主軸的顏色
- `--t0-tint` 等：主軸的淺色底
- 下面 `prefers-color-scheme: dark` 區塊是深色模式的顏色

## 換主軸名稱

打開 `js/config.js`，修改 `tracks`。名稱要和試算表「主軸」欄一字不差。

## 自訂網域（選用，需付費）

若立德想用 `learning.立德網域` 這種網址，需要另外購買網域（每年約 US$10–15），在 GitHub Pages 設定「Custom domain」。不設定也完全可以使用。
