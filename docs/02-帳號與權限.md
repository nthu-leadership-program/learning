# 帳號與權限

> **原則：平台用到的所有帳號都屬於立德，不使用任何人的個人帳號。** 建立者畢業後帳號跟著消失，是學習平台最常見的失敗原因。

## 帳號清單

> 密碼**不要**寫在這份文件裡（本 repo 是公開的）。密碼由【負責人／職位】統一保管，交接時當面移交。

| 服務 | 帳號 | 用途 | 管理者 |
|---|---|---|---|
| Google 共用帳號 | 【】 | YouTube、試算表、表單、雲端硬碟 | 【】 |
| GitHub Organization | 【】 | 網站與維護手冊 | 【】 |

## 重要連結

| 項目 | 連結 |
|---|---|
| 學習平台網站 | 【https://….github.io/…/】 |
| 內容試算表 `立德學習平台內容` | 【】 |
| 測驗紀錄試算表 | 【】 |
| YouTube 頻道 | 【】 |
| 雲端硬碟 `立德學習平台/` | 【】 |

## 雲端硬碟資料夾結構

```
立德學習平台/
├── 立德學習平台內容（試算表）    ← 網站的內容後台
├── 立德學習平台 測驗紀錄（表單＋試算表）
├── 授權/                         ← 講者與學員的同意紀錄
├── 原始影片/                     ← 未剪輯檔案備份
└── 講義/
```

## 權限分級

| 角色 | 內容試算表 | GitHub | 網站 |
|---|---|---|---|
| 平台管理者（1–2 人） | 擁有者 | Owner | — |
| 內容維護者（學弟妹） | 編輯者 | Member（需要改設定時） | — |
| 導師、學員 | — | — | 有網址就能看 |

> 網站本身沒有登入機制，靠「不公開網址」控管。如果網址外流到不該看的人手上，可以在 GitHub 把 repo 改名，網址就會跟著改變，再請老師更新官網上的連結。

## 新增或移除權限

- **新維護者加入**：共用內容試算表與雲端硬碟資料夾（編輯者），需要時邀請加入 GitHub Organization
- **成員離開**：上述權限全部移除，並在這裡記錄
