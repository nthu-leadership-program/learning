# 試算表欄位說明

試算表 `立德學習平台內容` 有兩個分頁：**單元**、**測驗**。

> ⚠️ **第一列的欄位名稱不能改**（網站靠欄位名稱讀資料）。欄位的順序可以調整，也可以在最後面加自己需要的欄位，網站會忽略看不懂的欄位。

第一次建立試算表時，可以直接匯入 `data/units.csv` 和 `data/quizzes.csv`：「檔案」→「匯入」→「上傳」，選「插入新工作表」。

## 「單元」分頁

一列＝一個單元。同一門課的單元，「課程ID」到「講者」都填一樣的內容。

| 欄位 | 必填 | 說明 | 範例 |
|---|---|---|---|
| 單元ID | ✓ | 每個單元獨一無二的代號，只用英文小寫、數字、`-`。**上架後不要改**，否則學員的進度會不見 | `swap-01` |
| 課程ID | ✓ | 同一門課的單元填一樣的 | `swap-school` |
| 課程名稱 | ✓ | 顯示在目錄的課程名稱 | `Swap School 跨域交換工作坊` |
| 主軸 | ✓ | 只能填 `搞順自己`、`挺好隊友`、`發揮影響力` 其中一個 | `發揮影響力` |
| 學期 | ✓ | 用於學期篩選 | `115-1` |
| 講者 | ✓ | | `王小明（○○公司）` |
| 順序 | ✓ | 單元在課程裡的順序，數字 | `1` |
| 單元名稱 | ✓ | | `為什麼要跨域交換` |
| YouTube網址 | ✓ | 直接貼影片網址 | `https://www.youtube.com/watch?v=...` |
| 長度 | | 顯示用 | `18 分鐘` |
| 單元介紹 | | 50–80 字，說明這個單元在講什麼、適合誰 | |
| 章節 | | 一行一個，格式 `分:秒 章節名稱`。第一行建議 `00:00` | `00:00 開場`<br>`03:15 交換的前提` |
| 重點筆記 | | 一行一個重點 | |
| 講義連結 | | 雲端硬碟講義的分享連結（權限設「知道連結的人可檢視」） | |
| 上架 | ✓ | `是` 才會顯示在網站上；其他值都當作草稿 | `是` |
| 主題標籤 | | 用頓號或逗號分隔。首頁會自動產生主題篩選按鈕，按使用次數排序。**同一個主題請用一模一樣的寫法**（例如不要混用「團隊合作」和「團隊協作」） | `自我認知、決策工具` |
| 學員心得 | | 「學長姐怎麼說」區塊。一行一則，可在後面用 `｜` 接署名。**必須匿名並取得本人同意**，見下方說明 | `原本只想交差，後來發現隊友補上我的盲點。｜第五屆學員` |
| 授權備註 | | 授權狀況，網站不會顯示 | `講者 10/5 Email 同意` |

### 主題標籤建議用詞

以下取自 115-1 學員回饋中提到的主題，新增標籤前先看看能不能沿用：

`自我認知`、`決策工具`、`團隊協作`、`表達溝通`、`領導力`、`跨域合作`、`個人品牌`、`時間管理`、`作業指引`

### 學員心得的規則

- **匿名**：署名只寫屆數，例如「第五屆學員」，不寫姓名或可辨識身分的描述
- **取得同意**：引用前先問本人「這句話可以匿名放在學習平台上嗎？」，並在「授權備註」記下
- **只放對學習有幫助的**：說明這堂課帶來什麼改變，不放對講者或同學的評價
- 不要放涉及個人隱私的內容（家庭、感情、身心狀況等）

## 「測驗」分頁

一列＝一題。

| 欄位 | 必填 | 說明 | 範例 |
|---|---|---|---|
| 單元ID | ✓ | 和「單元」分頁一模一樣 | `swap-01` |
| 題號 | ✓ | 同一個單元內的順序 | `1` |
| 題目 | ✓ | | |
| 選項A ~ 選項D | ✓ | 至少填 2 個選項；不用的選項留空 | |
| 答案 | ✓ | 只填 `A`、`B`、`C`、`D` | `B` |
| 解析 | | 答完後顯示，說明為什麼 | |
| 對應時間 | | 答案在影片的哪裡，格式 `分:秒`，會出現「回到這段複習」按鈕 | `03:15` |

## 發布到網路（第一次設定時做一次）

1. 「檔案」→「共用」→「發布到網路」
2. 第一個下拉選單選「**單元**」分頁，第二個選「**逗號分隔值 (.csv)**」
3. 按「發布」，複製網址
4. 重複一次，這次選「**測驗**」分頁
5. 把兩個網址貼到 `js/config.js`（見 [架設與部署](06-架設與部署.md)）

> 發布後，試算表的內容任何人都能看到，**不要放個資或內部資訊**。之後修改試算表會自動同步，約 5 分鐘內更新到網站。
