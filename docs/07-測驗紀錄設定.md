# 測驗紀錄設定（選填）

> 不設定也能使用網站，只是不會留下學員的測驗成績。需要統計試用數據或追蹤學習狀況時再設定。

設定後，學員每次送出測驗，網站會把「名字、單元ID、答對題數、總題數」送到一份 Google 表單，結果自動進入試算表。

## 1. 建立紀錄用表單

1. 用立德共用帳號建立新的 Google 表單，名稱 `立德學習平台 測驗紀錄`
2. 新增 4 題「簡答」，題目依序為：`名字`、`單元ID`、`答對題數`、`總題數`
3. **都不要設為必填**
4. 設定 ⚙️ →「回覆」：
   - 「收集電子郵件地址」選「不收集」
   - 「限制只能回覆 1 次」關閉（關閉後才不需要登入）
5. 「回覆」分頁 →「連結至試算表」，建立新的試算表

## 2. 取得欄位代號

1. 表單右上角「⋮」→「取得預先填入的連結」
2. 四題隨便填，例如 `a`、`b`、`c`、`d`，按「取得連結」→「複製連結」
3. 連結長得像這樣：

   ```
   https://docs.google.com/forms/d/e/1FAIpQLSxxxx/viewform?usp=pp_url&entry.111111=a&entry.222222=b&entry.333333=c&entry.444444=d
   ```

4. 從連結裡找出：
   - 表單網址：把 `viewform?...` 之後全部換成 `formResponse`
   - `entry.數字`：依序對應名字、單元ID、答對題數、總題數

## 3. 填進設定檔

在 GitHub 編輯 `js/config.js`：

```js
quizLog: {
  formResponseUrl: "https://docs.google.com/forms/d/e/1FAIpQLSxxxx/formResponse",
  fields: {
    name: "entry.111111",
    unit: "entry.222222",
    score: "entry.333333",
    total: "entry.444444"
  }
},
```

Commit 後，到網站做一次測驗，確認紀錄試算表有出現新的一列。

> 名字是學員自己填的（選填），不需要登入，所以這份紀錄適合拿來看整體使用狀況，不適合當作正式成績。
