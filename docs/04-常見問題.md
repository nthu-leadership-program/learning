# 常見問題

> 遇到新問題並解決後，請把問題和解法加到這裡。

### 內容沒更新
**Q：改了試算表，網站沒變？**
Google 發布的 CSV 約需 5 分鐘更新。等一下再重新整理；仍然沒變的話，確認「發布到網路」沒有被停止。

**Q：新單元沒有出現？**
依序檢查：「上架」欄是否為 `是`、「單元ID」有沒有填、「主軸」名稱是否一字不差。

**Q：測驗沒有出現？**
「測驗」分頁的「單元ID」要和「單元」分頁完全一樣，包括大小寫和 `-`。

**Q：網站顯示「讀不到課程資料」？**
`js/config.js` 裡的網址可能貼錯，或試算表被取消發布。重新「發布到網路」並複製網址。

### 影片
**Q：影片顯示「無法播放」？**
YouTube 瀏覽權限要選「不公開」，不能是「私人」。

**Q：點章節沒有跳到正確的時間？**
章節格式要是 `分:秒 名稱`，例如 `03:15 交換的前提`；超過一小時用 `1:02:30`。

### 測驗
**Q：答案明明對，卻顯示答錯？**
「答案」欄只能填 `A`、`B`、`C`、`D`，前後不要有其他字。

**Q：測驗紀錄沒有進試算表？**
見 [測驗紀錄設定](07-測驗紀錄設定.md)，確認表單沒有要求登入，且 `entry.數字` 沒有貼錯。

### 學員進度
**Q：學員說進度不見了？**
進度存在學員自己的瀏覽器，換裝置、用無痕視窗或清除瀏覽資料都會不見。這是目前版本的限制。

**Q：改了單元ID，大家的進度都不見了？**
進度是用單元ID 記錄的，上架後不要改單元ID。

### 其他
**Q：改壞了怎麼辦？**
- 試算表：「檔案」→「版本記錄」還原
- GitHub 上的檔案：打開檔案 →「History」，找到之前的版本，複製內容貼回來

**Q：不會用 GitHub？**
平常只需要改試算表。真的要改設定時，在網頁上點鉛筆圖示編輯就好，詳見 [README](../README.md)。
