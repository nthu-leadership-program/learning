# 新增單元 SOP

> 預估時間：第一次約 60 分鐘，熟練後約 30 分鐘（不含看影片）。
> 開始前請先登入**立德共用 Google 帳號**。整個流程**不需要碰程式碼**。

## 流程總覽

```
0 確認授權 → 1 上傳 YouTube → 2 填「單元」分頁 → 3 填「測驗」分頁 → 4 上架並檢查
```

---

## 步驟 0：確認授權（不能跳過）

- [ ] 講者同意影片上架
- [ ] 影片中出現的學員同意上架
- [ ] 確認對方同意「拿到連結的人都可以看」

> ⚠️ 這個平台**沒有登入機制**。如果講者只同意立德會員觀看，這支影片就不能放在這裡。沒有取得同意的影片一律不上架。

同意紀錄存到雲端硬碟 `立德學習平台/授權/`，並在試算表的「授權備註」欄寫一句說明。

## 步驟 1：上傳影片到 YouTube

1. 用立德共用帳號登入 YouTube Studio，點「建立」→「上傳影片」
2. **標題**：`【立德】單元名稱｜講者｜學期`
3. **觀眾**：選「否，這不是為兒童打造的內容」
4. **瀏覽權限**：選「**不公開**」（不要選「私人」，私人影片無法嵌入）
5. 發布後複製影片網址

> 建議邊看影片邊記下章節時間，步驟 2 會用到。

## 步驟 2：填「單元」分頁

打開 Google 試算表 `立德學習平台內容`，到「單元」分頁，**新增一列**。每一欄怎麼填見 [試算表欄位說明](05-試算表欄位說明.md)，重點：

| 欄位 | 範例 | 注意 |
|---|---|---|
| 單元ID | `swap-04` | 不可重複，只用英文、數字、`-` |
| 課程ID | `swap-school` | 同一門課的單元填一樣的 |
| 主軸 | `發揮影響力` | 只能填三大主軸之一，一字不差 |
| 章節 | `00:00 開場` | 一行一個章節，儲存格內換行用 `Alt + Enter`（Mac：`Option + Enter`） |
| 重點筆記 | | 一行一個重點 |
| 上架 | `否` | **先填「否」**，檢查完再改成「是」 |
| 主題標籤 | `自我認知、決策工具` | 盡量沿用已經有的標籤 |
| 學員心得 | | 選填；必須匿名並取得同意 |

## 步驟 3：填「測驗」分頁

1. 先依照 [測驗題目範本](../templates/測驗題目範本.md) 出題，**至少 2 題**
2. 到「測驗」分頁，每一題新增一列，「單元ID」要和步驟 2 一模一樣
3. 「答案」只填 `A`、`B`、`C` 或 `D`
4. 「對應時間」填這題答案出現在影片的哪裡，學員答錯時可以一鍵跳回去複習

沒有測驗的單元可以不填，網站會改顯示「標記為完成」按鈕。

## 步驟 4：上架並檢查

1. 把「上架」欄改成 `是`
2. **等約 5 分鐘**（Google 發布的 CSV 需要時間更新）
3. 打開學習平台網站，重新整理，用學員的角度檢查：

- [ ] 課程出現在正確的主軸下
- [ ] 影片可以播放
- [ ] 點章節會跳到對的時間
- [ ] 重點筆記沒有亂碼、換行正確
- [ ] 測驗可以作答，答案和解析正確
- [ ] 用手機打開也正常

有問題就先把「上架」改回 `否`，網站上就看不到這個單元，修好再上架。

> 💡 **改壞了怎麼辦？** Google 試算表有版本記錄：「檔案」→「版本記錄」→「查看版本記錄」，可以還原到任何一個時間點。
